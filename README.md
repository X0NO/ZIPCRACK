Welcome to my first GitHub project: a ZIP password cracker.

This project was developed using Python 3.13.13 and the zipfile, time, and colorama libraries. It also includes a password list containing 1 million of the most commonly used passwords on the internet.

I am still a beginner programmer, and I used Claude to help me debug and improve the code during development.
